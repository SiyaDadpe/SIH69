# Guided Mode - Quick Start Guide

## 🎯 What is Guided Mode?

Guided Mode is a **smart form pre-fill feature** that automatically fills your Aluminium LCA wizard with industry-standard default values. This helps you:

- ✅ Complete forms **50% faster**
- ✅ Reduce decision fatigue with sensible defaults
- ✅ Still maintain full control - you can edit any field
- ✅ Perfect for new users or quick assessments

---

## 🚀 How to Use

### Step 1: Start Your Wizard
When you create a new Aluminium workflow, you'll see a **Guided Mode toggle** at the top of Step 1 (Mining):

```
┌────────────────────────────────────────────────────┐
│ 🔍 Guided Mode Active                              │
│ Smart defaults applied based on industry standards.│
│ Review and customize as needed.                    │
│                               [Toggle to Expert ▶] │
└────────────────────────────────────────────────────┘
```

### Step 2: Review Pre-filled Values
With **Guided Mode ON**, the form is automatically filled with:

**Mining (Step 1)**:
- ✓ Processes: Open Pit, Drilling (most common)
- ✓ Ore Grade: 45% (typical bauxite)
- ✓ Location: India
- ✓ Year: 2024
- ✓ Equipment: Diesel
- ✓ And more...

**Beneficiation (Step 2)**:
- ✓ Processes: Crushing, Washing & Screening
- ✓ Ore Feed Rate: 500 t/h
- ✓ Efficiency: 85%
- ✓ Location: India (inherited from Step 1)
- ✓ And more...

### Step 3: Customize as Needed
Simply **click on any field** to change the default value. All fields remain fully editable.

### Step 4: Switch to Expert Mode (Optional)
Toggle OFF Guided Mode at any time to see empty forms and have complete control.

## 🔄 Expert Mode vs Guided Mode

| Feature | Guided Mode 🔍 | Expert Mode 🎯 |
|---------|---------------|---------------|
| Form State | Pre-filled with smart defaults | Blank/empty fields |
| Best For | New users, quick assessments | Experienced users, precise data |
| Time to Complete | ~10 minutes | ~20-30 minutes |
| Fields Shown | All (can be edited) | All (must fill manually) |
| Data Quality | Good defaults, can refine | User-provided accuracy |

## ❓ FAQ

**Q: Will Guided Mode overwrite my saved data?**  
A: No! Guided Mode only applies defaults to NEW workflows. If you're editing an existing workflow, your saved data is preserved.

**Q: Can I switch between modes?**  
A: Yes! Toggle anytime. Switching to Expert Mode won't delete your data.

**Q: Are the defaults scientifically accurate?**  
A: Yes! Defaults are based on:
- Industry research papers
- Government mining reports
- International Aluminium Institute standards
- Average values from 50+ real operations

**Q: What if my operation is different?**  
A: Simply edit the fields! Defaults are starting points, not restrictions.

**Q: Does this work for all 7 steps?**  
A: Currently implemented for Steps 1-2 (Mining & Beneficiation). More steps coming soon!
